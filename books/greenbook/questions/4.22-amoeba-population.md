## Problem

A pond starts with one amoeba. Every minute each amoeba independently dies, stays the same, splits into two, or splits into three, each with probability $\frac14$. What is the probability that the population eventually dies out?

## Solution

1. Let $p = P(\text{extinction}\mid\text{one amoeba})$. A group of $k$ amoebas behaves like $k$ independent copies, so it dies out with probability $p^k$.
2. Condition on the first minute:
$$\begin{aligned}p &= \tfrac14\big(1 + p + p^2 + p^3\big)\\ &\Rightarrow\; p^3 + p^2 - 3p + 1 = 0.\end{aligned}$$
3. Factor out the root $p = 1$:
$$\begin{aligned}(p - 1)(p^2 + 2p - 1) &= 0\\ \Rightarrow\; p&\in\{1,\ -1\pm\sqrt2\}.\end{aligned}$$
4. The extinction probability is the smallest root in $[0,1]$:
$$p = \sqrt2 - 1\approx 0.414.$$

**Why the smallest root.** $p_n = P(\text{extinct by minute } n)$ satisfies $p_{n+1} = g(p_n)$, $g(s) = \frac14(1+s+s^2+s^3)$, $p_0 = 0$. The iterates increase and can't pass a fixed point, so they stop at the first one: $\sqrt2-1$.

## Intuition

**Naive approach.** Track the population size minute by minute.

**Why it fails.** The state space grows without bound.

**The trick.** Use self-similarity: each offspring starts an independent copy of the same process. Mean offspring is $\frac{0+1+2+3}{4} = 1.5 > 1$, so survival is possible and $p<1$.

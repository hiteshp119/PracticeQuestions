## Problem

Compute
$$I = \int_{-\infty}^{\infty} e^{-x^2/2}\,dx.$$

## Solution

**Quick.** The $N(0,1)$ density $\frac{1}{\sqrt{2\pi}}e^{-x^2/2}$ integrates to 1, so $I = \sqrt{2\pi}$.

**Proof.**
1. Square, using a second variable:
$$I^2 = \int_{-\infty}^{\infty}\!\int_{-\infty}^{\infty} e^{-(x^2+y^2)/2}\,dx\,dy.$$
2. Polar: $x = r\cos\theta$, $y = r\sin\theta$, $dx\,dy = r\,dr\,d\theta$:
$$\begin{aligned}I^2 &= \int_0^{2\pi}\!\!\int_0^\infty e^{-r^2/2}\,r\,dr\,d\theta\\ &= 2\pi\Big[-e^{-r^2/2}\Big]_0^\infty = 2\pi.\end{aligned}$$
3. $I>0$, so $I = \sqrt{2\pi}$.

## Intuition

**Naive approach.** Find an antiderivative of $e^{-x^2/2}$.

**Why it fails.** It has none in elementary functions.

**The trick.** One copy is hard; **two copies** form $e^{-r^2/2}$, which depends only on the radius. The area element $r\,dr$ is exactly the derivative of $r^2/2$, so the 2-D integral is elementary.

**Going further.** Scaling: $\int e^{-ax^2}dx = \sqrt{\pi/a}$. That one formula gives every normal normalizing constant.

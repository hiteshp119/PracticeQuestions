## Problem

An array has zeros from the beginning up to some position, and nonzero values from then on. You don't know the array's size. How do you find the position of the first nonzero element?

## Solution

1. **Bracket.** Check $A[1], A[2], A[4], \dots$ until the first $k$ with $A[2^k]\ne0$. The answer $n$ satisfies $2^{k-1} < n\le2^k$ (taking $A[2^{-1}]$ as position 0 when $k = 0$). This takes $k+1\le\log_2n + 2$ probes.
2. **Binary search** in $(2^{k-1}, 2^k]$, an interval of length $2^{k-1} < n$: at most $\log_2n$ more probes.
```
hi = 1
while A[hi] == 0:
    hi *= 2
lo = hi // 2            # A[lo] == 0 (or lo = 0)
while hi - lo > 1:      # invariant: A[lo] == 0, A[hi] != 0
    mid = (lo + hi) // 2
    if A[mid] == 0: lo = mid
    else: hi = mid
return hi
```
3. Total $O(\log n)$, where $n$ is the answer's position, independent of the array's (unknown) length.

## Intuition

**Naive approach.** Scan from the start.

**Why it fails.** $O(n)$ probes.

**The trick.** When the search space is unbounded, grow the range geometrically until it contains the target, then search inside it. (Same idea as doubling a dynamic array.)

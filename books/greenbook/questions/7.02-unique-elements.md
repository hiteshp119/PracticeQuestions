## Problem

Given a sorted array, write code to extract its unique elements. Example: $[1,1,3,3,3,5,5,5,9,9,9,9]\to[1,3,5,9]$.

## Solution

1. Equal elements of a sorted array sit next to each other, so $a_i$ starts a new value iff $a_i\ne a_{i-1}$.
2. One pass:
```
def unique(a):
    out = [a[0]] if a else []
    for i in range(1, len(a)):
        if a[i] != a[i - 1]:
            out.append(a[i])
    return out
```
3. **In place** (as C++ `std::unique` does): keep a write index `w`; copy `a[i]` to `a[w]` and advance `w` when it differs from `a[w-1]`; the first `w` slots hold the answer.

Time $O(n)$, extra space $O(1)$ in place.

## Intuition

**Naive approach.** Put everything in a hash set.

**Why it fails.** It works but wastes the fact that the input is sorted (extra memory, and the output order must be restored).

**The trick.** Exploit the structure you're given: sortedness turns "have I seen this before?" into "is it equal to the previous element?".

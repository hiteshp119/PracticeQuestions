## Problem

$X_t$ starts at 0 with $dX = dW_t$. What is the probability that $X$ hits 3 before $-5$? What if $X$ has drift, $dX = m\,dt + dW_t$?

## Solution

**No drift.**
1. $X$ is a martingale; let $p = P(\text{hit } 3 \text{ first})$:
$$E[X_T] = 3p - 5(1-p) = 0 \;\Rightarrow\; p = \tfrac58.$$

**Drift $m$.**
1. $W_t = X_t - mt$, and $\exp(\lambda W_t - \frac12\lambda^2t)$ is a martingale for every $\lambda$:
$$\exp\Big(\lambda X_t - \big(\lambda m + \tfrac12\lambda^2\big)t\Big).$$
2. Choose $\lambda = -2m$ so the $t$ term vanishes: $Z_t = e^{-2mX_t}$ is a martingale.
3. Optional stopping:
$$p\,e^{-6m} + (1-p)\,e^{10m} = 1 \;\Rightarrow\; p = \frac{e^{10m} - 1}{e^{10m} - e^{-6m}}.$$
4. Check $m\to0$: $p\to\frac{10m}{16m} = \frac58$. ✓ (Same answer from the ODE $\frac12P'' + mP' = 0$, $P(3) = 1$, $P(-5) = 0$.)

## Intuition

**Naive approach.** Simulate or solve a PDE.

**Why it fails.** Both work, but the martingale route is one line.

**The trick.** Hitting probabilities come from a function $h(X)$ that is a martingale with known boundary values: $h(x) = x$ without drift, $h(x) = e^{-2mx}$ with drift ("scale function"). Then $h(0) = p\,h(3) + (1-p)h(-5)$.

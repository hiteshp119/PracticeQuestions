## Problem

How do you determine whether a positive integer $x$ is a power of 2?

## Solution

1. $x = 2^n$ in binary is a single 1 followed by $n$ zeros; $x - 1$ is $n$ ones:
$$8 = 1000_2,\qquad 7 = 0111_2.$$
2. They share no bits, so $x\,\&\,(x-1) = 0$.
3. If $x$ is not a power of 2, it has at least two 1-bits; subtracting 1 only changes bits from the lowest 1-bit down, so the highest 1-bit survives the AND: $x\,\&\,(x-1)\ne0$.
```
def is_power_of_two(x):
    return x > 0 and (x & (x - 1)) == 0
```
(Check $x>0$: $0\,\&\,(-1) = 0$ too.)

## Intuition

**Naive approach.** Divide by 2 while even; check you reach 1. $O(\log x)$.

**Why it fails.** Fine, but slower and longer than needed.

**The trick.** $x\,\&\,(x - 1)$ clears the lowest set bit, a staple of bit tricks: repeat it to count set bits (Kernighan), or use $x\,\&\,(-x)$ to isolate the lowest set bit.

## Problem

How do you swap the values of two integer variables $i$ and $j$ without using additional storage?

## Solution

1. **Arithmetic.** Store the sum, then peel each value off:
```
i = i + j      # i = a + b
j = i - j      # j = (a + b) - b = a
i = i - j      # i = (a + b) - a = b
```
Risk: $a + b$ may overflow a fixed-width integer (in two's complement the wrap-around still cancels, but it's undefined behaviour for signed ints in C/C++).
2. **XOR.** Uses $x\oplus x = 0$, $x\oplus0 = x$, and associativity:
```
i ^= j         # i = a ^ b
j ^= i         # j = b ^ (a ^ b) = a
i ^= j         # i = (a ^ b) ^ a = b
```
No overflow. **Pitfall:** if `i` and `j` refer to the same memory, the first line sets it to 0.

## Intuition

**Naive approach.** `tmp = i; i = j; j = tmp`.

**Why it fails.** Forbidden here (one extra variable).

**The trick.** Encode both values in one slot reversibly ($a + b$ or $a\oplus b$), then decode. In practice compilers swap via registers anyway, so this is an interview curiosity: prefer the readable version in real code.

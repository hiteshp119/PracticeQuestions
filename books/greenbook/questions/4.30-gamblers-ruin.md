## Problem

A gambler starts with $\$i$. Each game he wins $\$1$ with probability $p$ and loses $\$1$ with probability $q = 1-p$. He stops when he reaches $\$N$ or $\$0$. What is the probability he reaches $\$N$?

## Solution

1. First step from $0<i<N$:
$$P_i = pP_{i+1} + qP_{i-1},\qquad P_0 = 0,\ P_N = 1.$$
2. Since $P_i = pP_i + qP_i$:
$$\begin{aligned}p(P_{i+1} - P_i) &= q(P_i - P_{i-1})\\ \Rightarrow\; P_{k+1} - P_k &= \Big(\frac qp\Big)^k P_1.\end{aligned}$$
3. Sum the differences from $0$ to $i$:
$$P_i = P_1\sum_{k=0}^{i-1}\Big(\frac qp\Big)^k = \begin{cases}P_1\,\dfrac{1-(q/p)^i}{1-q/p}, & p\ne q\\[2mm] iP_1, & p = q.\end{cases}$$
4. $P_N = 1$ fixes $P_1$:
$$\begin{aligned}P_i &= \frac{1 - (q/p)^i}{1-(q/p)^N} && (p\ne\tfrac12),\\ P_i &= \frac iN && (p = \tfrac12).\end{aligned}$$

## Intuition

**Naive approach.** Sum over all win/loss paths that reach $N$ first.

**Why it fails.** Infinitely many paths, with the "don't hit 0 first" constraint.

**The trick.** First-step analysis turns a path problem into a linear recurrence on states. For $p = \frac12$ there is an even faster route: your fortune is a fair game (a martingale), so $E[\text{final}] = i$, i.e. $N\cdot P_i = i$ (card 5.07). Even a small edge matters a lot: with $p = 0.49$, $i = 50$, $N=100$, $P\approx 0.12$.

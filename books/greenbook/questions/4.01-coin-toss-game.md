## Problem

Player A has $n+1$ fair coins and player B has $n$. Both flip all their coins. What is the probability that A gets more heads than B?

## Solution

1. Compare A's first $n$ coins with B's $n$ coins:
$$\begin{aligned}x &= P(A_n > B) = P(A_n < B)\ \text{(symmetry)}\\ y &= P(A_n = B),\qquad 2x + y = 1.\end{aligned}$$
2. Now add A's last coin:
   - $A_n > B$: A still wins.
   - $A_n < B$: one more head gives at most a tie, so A doesn't win.
   - $A_n = B$: A wins iff the last coin is heads, probability $\frac12$.
3. So
$$P(A \text{ wins}) = x + \tfrac12 y = x + \tfrac12(1 - 2x) = \tfrac12.$$

## Intuition

**Naive approach.** Sum binomial probabilities $\sum_k P(A = k)\,P(B < k)$.

**Why it fails.** It is correct but gives no closed form you can see in an interview.

**The trick.** Make the problem symmetric by removing the asymmetry (one coin), solve the symmetric part, then add the piece back. Equivalently: A has more heads than B **or** more tails than B, never both, and the two events have equal probability.

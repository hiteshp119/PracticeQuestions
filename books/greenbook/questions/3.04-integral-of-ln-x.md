## Problem

Find $\displaystyle\int \ln x \, dx$ for $x>0$.

## Solution

1. Parts: $\int u\,dv = uv - \int v\,du$ with
$$u = \ln x,\quad du = \frac{dx}{x},\qquad dv = dx,\quad v = x.$$
2. Then
$$\begin{aligned}\int \ln x\,dx &= x\ln x - \int x\cdot\frac1x\,dx\\ &= x\ln x - x + C.\end{aligned}$$
3. Check: $\dfrac{d}{dx}(x\ln x - x) = \ln x + 1 - 1 = \ln x$. ✓

## Intuition

**Naive approach.** Look for a function whose derivative is $\ln x$ in a table of derivatives.

**Why it fails.** $\ln x$ only appears there as an *output* of $x\ln x - x$, which you would have to already know.

**The trick.** Write $\ln x = 1\cdot\ln x$. Parts lets you differentiate the awkward factor ($\ln x \to 1/x$) and integrate the easy one ($1 \to x$). The same move integrates $\arctan x$ and $\arcsin x$.

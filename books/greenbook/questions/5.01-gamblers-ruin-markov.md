## Problem

Player M has \$1 and player N has \$2. Each game moves \$1 from the loser to the winner; M wins each game with probability $\frac23$. They play until one is broke. What is the probability that M wins everything?

## Solution

1. State $m$ = M's money $\in\{0,1,2,3\}$. Absorbing: $0$ (M ruined) and $3$ (M wins).
2. Let $a_m$ = P(reach 3 from $m$). First step:
$$a_1 = \tfrac13\cdot0 + \tfrac23 a_2,\qquad a_2 = \tfrac13 a_1 + \tfrac23\cdot1.$$
3. Substitute:
$$\begin{aligned}a_1 &= \tfrac23\big(\tfrac13a_1 + \tfrac23\big) = \tfrac29a_1 + \tfrac49\\ \Rightarrow\; \tfrac79a_1 &= \tfrac49 \;\Rightarrow\; a_1 = \tfrac47.\end{aligned}$$
4. Check with card 4.30, $q/p = \frac12$: $\frac{1 - (1/2)^1}{1 - (1/2)^3} = \frac{1/2}{7/8} = \frac47$. ✓

## Intuition

**Naive approach.** "M is the better player, so he's the favourite." Or "N has twice the money, so N is the favourite."

**Why it fails.** Both effects matter and you need numbers to see which wins.

**The trick.** A Markov chain turns the game into a few linear equations: one unknown per non-absorbing state. Here skill (2:1 odds) beats bankroll (1:2) slightly.

## Problem

You solve a parabolic PDE with the explicit finite difference method. Is it worse to have too many steps in the time dimension or too many in the space dimension?

## Solution

1. Explicit update:
$$\begin{aligned}u^{n+1}_j &= \alpha u^n_{j-1} + (1-2\alpha)u^n_j + \alpha u^n_{j+1},\\ \alpha &= \frac{\Delta\tau}{\Delta x^2}.\end{aligned}$$
2. If $\alpha\le\frac12$, all three weights are $\ge0$ and sum to 1: each new value is an average of old ones, so errors can't grow (maximum principle).
3. If $\alpha>\frac12$, the middle weight is negative. Von Neumann analysis: a mode $u^n_j = g^ne^{ikj\Delta x}$ has
$$g = 1 - 4\alpha\sin^2\tfrac{k\Delta x}{2},$$
and for the highest frequency $g = 1 - 4\alpha < -1$: errors double in size and flip sign every step.
4. More **time** steps ⇒ smaller $\Delta\tau$ ⇒ smaller $\alpha$: safe (just slower). More **space** steps ⇒ smaller $\Delta x$ ⇒ $\alpha$ grows like $\frac1{\Delta x^2}$: can make the scheme unstable. So too many space steps is worse. Implicit and Crank–Nicolson schemes are unconditionally stable.

## Intuition

**Naive approach.** "More grid points always means more accuracy."

**Why it fails.** For explicit schemes, information can only travel one grid cell per time step; with tiny $\Delta x$ and a fixed $\Delta\tau$, the true diffusion outruns the scheme and errors explode.

**The trick.** Check the weights: a scheme that writes the new value as a positive average of old values is stable. The widget shows the blow-up the moment $\alpha$ crosses $\frac12$.

## Problem

A bag holds 20 blue and 14 red balls. Repeatedly draw two balls at random and do not return them. If they're the same colour, add a blue ball; if different, add a red ball. Continue until one ball remains. What colour is it? What if you start with 20 blue and 13 red?

## Solution

Track $(B,R)$:

| drawn | change |
|---|---|
| blue + blue | $(B,R)\to(B-1,\ R)$ |
| red + red | $(B,R)\to(B+1,\ R-2)$ |
| blue + red | $(B,R)\to(B-1,\ R)$ |

So $R$ changes by $0$ or $-2$: **$R \bmod 2$ is invariant.** The total drops by 1 each step, so we end at one ball.

- Start $R = 14$ (even): $R$ can never be 1, so the last ball is **blue**.
- Start $R = 13$ (odd): $R$ can never be 0, so the last ball is **red**.

The randomness doesn't matter at all.

## Intuition

**Naive approach.** Simulate, or compute probabilities of each draw sequence.

**Why it fails.** The draws are random but the answer is certain. Probability is a red herring.

**The trick.** When a process has random steps but a definite answer, look for an **invariant**: a quantity (here red parity) that no step can change.

## Problem

Write down put–call parity for European options on a non-dividend-paying stock, and prove it.

## Solution

1. Same strike $K$, same maturity $T$. Portfolio A: one call + a zero-coupon bond paying $K$ at $T$. Portfolio B: one put + one share.
2. Payoffs at $T$:
$$\begin{aligned}A&: (S_T - K)^+ + K = \max(S_T, K),\\ B&: (K - S_T)^+ + S_T = \max(S_T, K).\end{aligned}$$
3. No cash flows before $T$. If A and B had different prices, buy the cheap one and sell the dear one: riskless profit today, zero at $T$. So
$$c + Ke^{-rT} = p + S.$$
4. **Forward view.** $c - p$ pays $(S_T-K)^+ - (K-S_T)^+ = S_T - K$: a forward with delivery price $K$, worth $S - Ke^{-rT}$. When $K$ equals the forward price $Se^{rT}$, call = put.

With dividends (present value $D$): $c + Ke^{-rT} = p + S - D$. For American options only bounds hold: $S - D - K \le C - P \le S - Ke^{-rT}$.

## Intuition

**Naive approach.** Derive both prices from Black–Scholes and subtract.

**Why it fails.** Parity needs no model at all; using one hides that.

**The trick.** Static replication: find portfolios with identical payoffs. A call is a put plus a forward, which is why calls and puts share the same gamma and vega.

## Problem

An array $A$ of length $n$ has positive and negative numbers. Design an algorithm to find the maximum sum $\sum_{x=i}^jA_x$ over all contiguous subarrays. Apply it to $A = [1, 2, -5, 4, -3, 2, 6, -5, -1]$.

## Solution

1. **Prefix sums.** $T(j) = \sum_{x\le j}A_x$, $T(0) = 0$. Then
$$V(i,j) = T(j) - T(i-1).$$
2. For fixed $j$, $V$ is largest when $T(i-1)$ is smallest among $T(0),\dots,T(j-1)$. Keep a running minimum:
```
def max_subarray(A):
    T, T_min, best = 0, 0, A[0]
    for a in A:
        T += a
        best = max(best, T - T_min)
        T_min = min(T_min, T)
    return best
```
3. Example: $T = 1, 3, -2, 2, -1, 1, 7, 2, 1$. At $j = 7$ ($T = 7$), the smallest earlier prefix is $-2$ (after $j = 3$):
$$V = 7 - (-2) = 9,$$
from the subarray $A[4..7] = [4, -3, 2, 6]$.
4. $O(n)$ time, $O(1)$ memory. (Equivalent Kadane form: `cur = max(a, cur + a); best = max(best, cur)`.)

## Intuition

**Naive approach.** Try all pairs $(i,j)$: $O(n^2)$ (or $O(n^3)$ without prefix sums).

**Why it fails.** It recomputes overlapping information.

**The trick.** Turn "best interval" into "best difference of prefix sums with the smaller one first", the same as maximum run-up (or, flipped, maximum drawdown) of a P&L curve: track the lowest point so far.

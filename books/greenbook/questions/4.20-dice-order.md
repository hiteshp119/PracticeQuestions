## Problem

Three fair dice are thrown one after another. What is the probability that the three results are in strictly increasing order?

## Solution

1. All different: $\frac{6\cdot5\cdot4}{6^3} = \frac{5}{9}$.
2. Given 3 different values, each of the $3! = 6$ orders is equally likely, and exactly one is increasing: $\frac16$.
3.
$$P = \frac59\cdot\frac16 = \frac5{54}\approx 0.0926.$$
Equivalently: each 3-element subset of $\{1,\dots,6\}$ gives exactly one increasing sequence, so $\frac{\binom63}{6^3} = \frac{20}{216}$.

## Intuition

**Naive approach.** Enumerate: first die 1, second 2, third 3–6; …

**Why it fails.** Long case lists invite mistakes.

**The trick.** Separate *which* values appear from *their order*. Order is uniform by symmetry, so only one in $3!$ is increasing.

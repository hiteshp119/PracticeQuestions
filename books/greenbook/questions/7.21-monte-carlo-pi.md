## Problem

How can you use Monte Carlo simulation to estimate $\pi$? How accurate is it?

## Solution

1. Draw $(x_i,y_i)$ independent uniform on $[0,1]^2$. The quarter disc $x^2 + y^2\le1$ has area $\frac\pi4$, so
$$p = P(x^2 + y^2\le1) = \frac\pi4.$$
2. Estimate:
$$\hat\pi = 4\cdot\frac{\#\{i: x_i^2 + y_i^2\le1\}}{M}.$$
3. Each indicator is Bernoulli($p$):
$$\begin{aligned}\operatorname{SE}(\hat\pi) &= 4\sqrt{\frac{p(1-p)}{M}}\\ &= \frac{4\sqrt{0.785\times0.215}}{\sqrt M}\approx\frac{1.64}{\sqrt M}.\end{aligned}$$
$M = 10^6$ gives about $\pm0.0016$: only 2–3 correct decimals.

## Intuition

**Naive approach.** Expect many digits from many points.

**Why it fails.** Monte Carlo error falls like $1/\sqrt M$: each extra digit costs 100× the points.

**The trick.** It's the area-as-probability idea (cards 4.33, 4.34) run backwards. For a better estimate, integrate $\sqrt{1 - x^2}$ (lower variance) or use quasi-random points.

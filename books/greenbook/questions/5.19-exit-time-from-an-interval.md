## Problem

What is the expected time for a standard Brownian motion started at 0 to reach either $-1$ or $1$?

## Solution

1. Itô: $d(B_t^2 - t) = 2B_t\,dB_t + dt - dt = 2B_t\,dB_t$: no drift, so $B_t^2 - t$ is a martingale.
2. $T = \min\{t: B_t = \pm1\}$. Optional stopping (bounded, $E[T]<\infty$):
$$E[B_T^2 - T] = B_0^2 - 0 = 0.$$
3. $B_T = \pm1$, so $B_T^2 = 1$:
$$E[T] = 1.$$
4. For the interval $(-b, a)$: $P(\text{hit } a) = \frac{b}{a+b}$ and $E[T] = E[B_T^2] = \frac{b}{a+b}a^2 + \frac{a}{a+b}b^2 = ab$ (continuous version of card 5.07).

## Intuition

**Naive approach.** Solve for the distribution of $T$, then take its mean.

**Why it fails.** The distribution of the exit time is an infinite series; the mean is much easier.

**The trick.** Variance of $B_t$ grows like $t$, so "$B^2$ minus time" is fair. At exit, $B^2$ is known exactly; the clock must make up the rest.

## Problem

Solve for $x$:
$$x^{x^{x^{\cdot^{\cdot^{\cdot}}}}} = 2.$$

## Solution

Let $T = x^{x^{x^{\cdots}}}$. Removing the bottom $x$ leaves the same infinite tower, so

$$T = x^{T}.$$

With $T = 2$:
$$2 = x^2 \;\Rightarrow\; x = \sqrt 2 \quad (x>0).$$

**Check that the tower really converges.** Define $t_1 = \sqrt2,\ t_{k+1} = \sqrt2^{\,t_k}$. If $t_k < 2$ then $t_{k+1} < \sqrt2^{\,2} = 2$, and the sequence increases, so it converges to a fixed point $\le 2$. The fixed points of $t=\sqrt2^{\,t}$ are $2$ and $4$, so the limit is $2$. ✓

## Intuition

**Naive approach.** Expand a few levels: $x^{x}$, $x^{x^x}$… and guess.

**Why it fails.** Finite towers never equal 2 exactly; the question is about the limit.

**The trick.** Self-similarity: an infinite object that contains a copy of itself satisfies an equation. **But check convergence.** "$x^{x^{\cdots}}=4$" gives $x^4=4$, so again $x=\sqrt2$. The same $x$ can't produce both 2 and 4. The tower with $x=\sqrt2$ converges to 2, so the equation with 4 has **no** solution. In general the tower converges only for $e^{-e}\le x\le e^{1/e}$, and its value never exceeds $e$.

## Problem

11 pirates lock their treasure in a safe. Any 6 of them together must be able to open every lock; no group of 5 may. Each lock can have several keys, and a pirate can hold several keys. What is the minimum number of locks, and how many keys does each pirate carry?

## Solution

1. **Lower bound.** Take any 5-group $G$. Since $G$ can't open the safe, some lock $L_G$ has no key in $G$. Each pirate outside $G$ joined with $G$ makes 6, who can open $L_G$, so **all 6 outsiders hold $L_G$'s key**.
2. **Different groups need different locks.** If $L_G = L_H$ for $G\ne H$, pick a pirate $p\in H\setminus G$: $p$ is outside $G$ so holds the key, but $p\in H$ cannot. Contradiction.
3. So at least
$$\binom{11}{5} = 462 \text{ locks.}$$
4. **It suffices.** One lock per 5-group, keys to its 6 complements. Any 6 pirates include someone outside every 5-group, so they open all locks; a 5-group $G$ can't open $L_G$.
5. **Keys per pirate.** A pirate holds the key to $L_G$ iff they are not in $G$: the number of 5-groups among the other 10:
$$\binom{10}{5} = 252 \quad\Big(\text{check: } \tfrac{462\cdot 6}{11} = 252\Big).$$

## Intuition

**Naive approach.** Try small designs by hand with a few locks.

**Why it fails.** Every 5-group needs its own blocking lock; any design with fewer locks leaves some 5-group able to open everything.

**The trick.** Think from the **adversary's** side: each maximal "bad" group must be blocked by something only it lacks. That gives a one-to-one map from bad groups to locks. (Shamir's secret sharing does this with polynomials instead of locks.)

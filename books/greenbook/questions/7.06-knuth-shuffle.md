## Problem

You have a generator of uniform random numbers. How do you shuffle a 52-card deck so that every permutation is equally likely?

## Solution

1. **Sort by random keys.** Attach an independent $U(0,1)$ to each card and sort. All orders equally likely by symmetry; $O(n\log n)$.
2. **Fisher–Yates (Knuth) shuffle**, $O(n)$:
```
for i in range(n - 1):
    j = random.randint(i, n - 1)    # uniform on i..n-1, inclusive
    A[i], A[j] = A[j], A[i]
```
3. **Why it's uniform.** Step $i$ chooses uniformly which of the $n - i$ remaining cards goes to position $i$. The choices give $n(n-1)\cdots1 = n!$ equally likely sequences, and different sequences give different permutations: each permutation has probability $\frac1{n!}$.
4. **Classic bug.** `j = randint(0, n-1)` (swap with any position) gives $n^n$ equally likely outcomes; $n!$ doesn't divide $n^n$ (e.g. $3^3 = 27$ vs $6$), so some permutations are more likely.

## Intuition

**Naive approach.** "Swap each card with a random card."

**Why it fails.** Counting outcomes: $n^n$ paths can't split evenly into $n!$ permutations.

**The trick.** Build the permutation position by position, choosing uniformly among what's left: like drawing cards from a hat.

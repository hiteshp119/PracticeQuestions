## Problem

Find the eigenvalues and eigenvectors of
$$A = \begin{pmatrix} 2 & 1 \\ 1 & 2\end{pmatrix}.$$

## Solution

1. **Characteristic equation.**
$$\begin{aligned}\det(A - \lambda I) &= (2-\lambda)^2 - 1 = 0\\ \Rightarrow\; 2 - \lambda &= \pm1 \;\Rightarrow\; \lambda \in\{1, 3\}.\end{aligned}$$
(Shortcut: $\lambda_1+\lambda_2 = \operatorname{tr}A = 4$, $\lambda_1\lambda_2 = \det A = 3$.)
2. **$\lambda = 3$:** $(A - 3I)v = \begin{pmatrix}-1&1\\1&-1\end{pmatrix}v = 0 \Rightarrow v_1 = v_2$, so $v = \frac1{\sqrt2}(1,1)$.
3. **$\lambda = 1$:** $(A - I)v = \begin{pmatrix}1&1\\1&1\end{pmatrix}v = 0 \Rightarrow v_1 = -v_2$, so $v = \frac1{\sqrt2}(1,-1)$.
4. Check: $A(1,1)^\top = (3,3)^\top$, $A(1,-1)^\top = (1,-1)^\top$. ✓

## Intuition

**Naive approach.** Expand the characteristic polynomial and use the quadratic formula every time.

**Why it fails.** It works, but misses the structure that makes larger versions easy.

**The trick.** Add and subtract the two equations of $Av = \lambda v$:
$$3(v_1 + v_2) = \lambda(v_1+v_2),\qquad (v_1 - v_2) = \lambda(v_1 - v_2).$$
So "sum" and "difference" directions are the eigenvectors. Any matrix $\begin{pmatrix}a&b\\b&a\end{pmatrix}$ has eigenvalues $a\pm b$ on $(1,\pm1)$; e.g. a 2-asset correlation matrix has eigenvalues $1\pm\rho$.

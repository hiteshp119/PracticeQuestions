## Problem

Solve
$$y' + 6xy = 0,\qquad y(0) = 1.$$

## Solution

1. $y' = -6x\,y$ has the form $g(x)h(y)$. Separate:
$$\frac{dy}{y} = -6x\,dx.$$
2. Integrate:
$$\ln|y| = -3x^2 + C \;\Rightarrow\; y = A\,e^{-3x^2}.$$
3. $y(0) = A = 1$, so
$$y = e^{-3x^2}.$$
4. Check: $y' = -6x\,e^{-3x^2} = -6xy$. ✓

## Intuition

**Naive approach.** Guess an exponential $e^{kx}$.

**Why it fails.** The rate $-6x$ changes with $x$, so a fixed $k$ cannot work.

**The trick.** $y'/y = (\ln y)'$ is the instantaneous growth rate. Here it is $-6x$, so $\ln y$ is its antiderivative, $-3x^2$. Any linear first-order ODE with no forcing term ($y' = p(x)\,y$) solves as $y = y_0\,e^{\int p}$.

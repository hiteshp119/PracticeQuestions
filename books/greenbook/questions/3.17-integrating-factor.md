## Problem

For $x>0$, solve
$$y' + \frac{y}{x} = \frac{1}{x^2},\qquad y(1) = 1.$$

## Solution

1. Form $y' + P(x)y = Q(x)$ with $P = \frac1x$, $Q = \frac1{x^2}$.
2. Integrating factor:
$$I(x) = e^{\int \frac{dx}{x}} = e^{\ln x} = x.$$
3. Multiply through:
$$x y' + y = (xy)' = \frac{1}{x}.$$
4. Integrate:
$$xy = \ln x + c \;\Rightarrow\; y = \frac{\ln x + c}{x}.$$
5. $y(1) = c = 1$:
$$y = \frac{\ln x + 1}{x}.$$
6. Check: $y' = \frac{1 - (\ln x + 1)}{x^2} = -\frac{\ln x}{x^2}$, and $y' + \frac yx = \frac{-\ln x + \ln x + 1}{x^2} = \frac1{x^2}$. ✓

## Intuition

**Naive approach.** Separate variables.

**Why it fails.** The forcing term $1/x^2$ is added, not multiplied, so $y$ and $x$ won't split.

**The trick.** Find $I$ that makes the left side a product-rule derivative: $(Iy)' = Iy' + I'y$ matches $I(y' + Py)$ when $I' = IP$, i.e. $I = e^{\int P}$. Here you can even spot it: $xy' + y$ is already $(xy)'$.

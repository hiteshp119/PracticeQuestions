## Problem

Explain a few variance reduction techniques that improve the efficiency of Monte Carlo simulation.

## Solution

Plain Monte Carlo: $\hat Y = \frac1M\sum Y_i$, $\operatorname{Var}(\hat Y) = \frac{\sigma^2}{M}$. Reduce $\sigma^2$ while keeping $E$ unchanged:

1. **Antithetic variates.** For each normal draw $\varepsilon$ also use $-\varepsilon$; average $\frac{Y(\varepsilon) + Y(-\varepsilon)}2$. Variance per pair $\frac{\sigma^2}{2}(1+\rho)$; it helps when $\rho = \operatorname{corr}(Y(\varepsilon), Y(-\varepsilon)) < 0$, true for monotone payoffs.
2. **Control variates.** Price $X$ alongside a similar $Y$ with a known value $E[Y]$, using the same random numbers:
$$\begin{aligned}\hat X_{cv} &= \hat X + \beta\big(E[Y] - \hat Y\big),\\ \beta^* &= \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(Y)}.\end{aligned}$$
Variance falls by the factor $1 - \rho_{XY}^2$. E.g. arithmetic Asian option with the geometric Asian (closed form) as control; or the stock itself, whose discounted mean is known.
3. **Importance sampling.** $E_f[h(X)] = E_g\big[h(X)\frac{f(X)}{g(X)}\big]$: sample from $g$ that puts more paths where $h\ne0$ (deep OTM options), and reweight.
4. **Moment matching.** Rescale the drawn normals so their sample mean is 0 and variance 1 exactly.
5. **Low-discrepancy sequences** (Sobol, Halton): deterministic points that fill space evenly; error roughly $O(\frac{(\log M)^d}{M})$ instead of $O(M^{-1/2})$.

## Intuition

**Naive approach.** Just run more paths.

**Why it fails.** Error falls only like $1/\sqrt M$: 100× the cost for 10× the accuracy.

**The trick.** Spend effort on knowledge instead of paths: symmetry (antithetic), a known answer to a similar problem (control variate), or sampling where it matters (importance).

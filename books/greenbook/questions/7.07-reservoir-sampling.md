## Problem

Characters in a file can only be read sequentially, and the file's length is unknown. How do you pick one character so that every character has the same probability of being chosen?

## Solution

1. Keep one pick. On reading the $i$-th character, replace the pick with it with probability $\frac1i$ (so the 1st is always taken).
```
pick = None
for i, ch in enumerate(stream, start=1):
    if random.random() < 1 / i:
        pick = ch
```
2. **Proof.** If there are $m$ characters, character $k$ ends as the pick iff it is taken at step $k$ and not replaced at steps $k+1..m$:
$$\frac1k\cdot\frac{k}{k+1}\cdot\frac{k+1}{k+2}\cdots\frac{m-1}{m} = \frac1m.$$
3. One pass, $O(1)$ memory. To pick $s$ items: keep a reservoir of $s$; the $i$-th item enters with probability $\frac si$, replacing a uniformly random member.

## Intuition

**Naive approach.** Read the whole file to find $m$, then pick a random index.

**Why it fails.** That needs two passes or storing everything; the stream may be huge or infinite.

**The trick.** Maintain the invariant "after $i$ characters, the pick is uniform over those $i$". Induction shows probability $\frac1i$ for the newcomer keeps it true.

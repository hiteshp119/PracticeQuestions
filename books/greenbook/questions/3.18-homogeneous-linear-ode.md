## Problem

Find the general solution of
$$y'' + y' + y = 0.$$

## Solution

1. Try $y = e^{rx}$: $(r^2 + r + 1)e^{rx} = 0$, so
$$\begin{aligned}&r^2 + r + 1 = 0\\ &\Rightarrow\; r = \frac{-1\pm\sqrt{1-4}}{2} = -\frac12 \pm i\,\frac{\sqrt3}{2}.\end{aligned}$$
2. Complex pair $\alpha\pm i\beta$ with $\alpha = -\frac12$, $\beta = \frac{\sqrt3}2$. By Euler, $e^{(\alpha\pm i\beta)x} = e^{\alpha x}(\cos\beta x \pm i\sin\beta x)$; the real and imaginary parts are two real independent solutions.
3. General solution:
$$y = e^{-x/2}\Big(c_1\cos\tfrac{\sqrt3}{2}x + c_2\sin\tfrac{\sqrt3}{2}x\Big).$$

**All three cases of $ar^2 + br + c = 0$:**
- real $r_1\ne r_2$: $c_1e^{r_1x} + c_2e^{r_2x}$;
- double root $r$: $(c_1 + c_2x)\,e^{rx}$;
- complex $\alpha\pm i\beta$: $e^{\alpha x}(c_1\cos\beta x + c_2\sin\beta x)$.

## Intuition

**Naive approach.** Integrate twice.

**Why it fails.** $y''$ depends on $y$ and $y'$; you can't integrate it on its own.

**The trick.** Exponentials are the functions whose derivatives are multiples of themselves, so $e^{rx}$ turns the ODE into a quadratic. Physically this is a damped spring ($b=1$ friction, $c=1$ stiffness): $b^2 < 4ac$ means under-damped, so it oscillates while decaying.

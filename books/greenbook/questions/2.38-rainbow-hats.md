## Problem

Seven prisoners each get a hat in one of the 7 rainbow colours, chosen by the executioner (possibly adversarially). Each sees the other six hats but not his own. Without communicating, all simultaneously write down a guess of their own colour. If **at least one** guesses right, all go free. Is there a strategy that guarantees freedom?

## Solution

Code colours $0,\dots,6$ and number the prisoners $i = 0,\dots,6$. Let $x_i$ be prisoner $i$'s hat and
$$S = \sum_{j=0}^{6} x_j \bmod 7.$$

**Strategy:** prisoner $i$ assumes $S = i$ and guesses
$$g_i = \Big(i - \sum_{j \ne i} x_j\Big) \bmod 7.$$

Then $g_i = x_i \iff S = i$. Since $S$ takes exactly one value in $\{0,\dots,6\}$, **exactly one** prisoner (the one with $i = S$) is right. They always go free.

## Intuition

**Naive approach.** Everyone guesses randomly: $P(\text{all wrong}) = (6/7)^7 \approx 34\%$.

**Why it fails.** Independent guesses overlap; several prisoners can be right at once while in other cases nobody is.

**The trick.** **Coordinate the errors.** Each prisoner covers a different possible value of the total, so the 7 guesses partition all possibilities and exactly one is right every time. Same checksum idea as the prisoner problem, but here no one hears anyone.

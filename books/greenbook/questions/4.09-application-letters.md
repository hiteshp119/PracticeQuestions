## Problem

You have 5 cover letters and 5 envelopes, each addressed to one of 5 firms. A child puts the letters into the envelopes at random. What is the probability that every letter is in the wrong envelope?

## Solution

1. $E_i$: letter $i$ is in its own envelope. We want $1 - P\big(\bigcup E_i\big)$.
2. For any set of $k$ letters, all correct with probability $\frac{(5-k)!}{5!}$; there are $\binom5k$ sets, so
$$S_k = \binom5k\frac{(5-k)!}{5!} = \frac1{k!}.$$
3. Inclusion–exclusion:
$$\begin{aligned}P\Big(\bigcup E_i\Big) &= S_1 - S_2 + S_3 - S_4 + S_5\\ &= 1 - \frac12 + \frac16 - \frac1{24} + \frac1{120} = \frac{19}{30}.\end{aligned}$$
4. So
$$P(\text{all wrong}) = \frac{11}{30}\approx 0.367$$
(44 derangements out of 120 permutations).

## Intuition

**Naive approach.** Count derangements by listing.

**Why it fails.** There are 120 permutations; listing is slow and error-prone.

**The trick.** "None" is hard, "at least one" is a union, and unions of symmetric events are what inclusion–exclusion is for. The terms $\frac1{k!}$ give the partial sums of $e^{-1}$, so for large $n$ the answer is $\approx 0.368$ regardless of $n$.

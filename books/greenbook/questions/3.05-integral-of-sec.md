## Problem

Compute
$$\int_0^{\pi/6} \sec x\, dx.$$

## Solution

1. From $(\cos x)' = -\sin x$ and the quotient rule:
$$\begin{aligned}(\sec x)' &= \frac{\sin x}{\cos^2 x} = \sec x\tan x,\\ (\tan x)' &= \frac{\cos^2x+\sin^2x}{\cos^2x} = \sec^2 x.\end{aligned}$$
2. Add them:
$$(\sec x + \tan x)' = \sec x\,(\sec x + \tan x).$$
3. So $\sec x$ is a log-derivative:
$$\int \sec x\,dx = \ln|\sec x + \tan x| + C.$$
4. Evaluate: $\sec\frac\pi6 = \frac{2}{\sqrt3}$, $\tan\frac\pi6 = \frac1{\sqrt3}$, and $\sec 0 + \tan 0 = 1$:
$$\begin{aligned}\int_0^{\pi/6}\sec x\,dx &= \ln\Big(\frac{3}{\sqrt3}\Big) - \ln 1\\ &= \ln\sqrt3 \approx 0.5493.\end{aligned}$$

## Intuition

**Naive approach.** Substitute $u = \cos x$.

**Why it fails.** $\sec x\,dx = \frac{dx}{\cos x}$ has no $\sin x$ to pair with $du = -\sin x\,dx$.

**The trick.** Look for $g$ with $g'/g = \sec x$. Differentiating $\sec x$ and $\tan x$ shows each derivative contains the other, so their sum reproduces itself times $\sec x$.

**Going further.** Multiplying by $\frac{\cos x}{\cos x}$ also works: $\int \frac{\cos x}{1-\sin^2x}dx$, then $u = \sin x$ and partial fractions give $\frac12\ln\frac{1+\sin x}{1-\sin x}$, the same function.

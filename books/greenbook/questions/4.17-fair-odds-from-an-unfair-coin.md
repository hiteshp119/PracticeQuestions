## Problem

You have a coin that lands heads with some unknown probability $p\in(0,1)$. How can you use it to generate a fair (50-50) outcome?

## Solution

1. Toss twice. With $q = 1-p$:
$$\begin{aligned}P(HH) &= p^2, & P(HT) &= pq,\\ P(TH) &= qp, & P(TT) &= q^2.\end{aligned}$$
2. Declare $HT$ = "win", $TH$ = "lose", and **repeat** on $HH$ or $TT$.
3. Each round ends with probability $2pq$, and given that it ends,
$$P(\text{win}) = \frac{pq}{2pq} = \frac12.$$
4. Expected number of tosses: $\frac{2}{2pq} = \frac1{pq}$ (4 tosses for a fair coin; many more for a heavily biased one).

## Intuition

**Naive approach.** Estimate $p$ from many tosses and correct for it.

**Why it fails.** Any estimate has error, so the result is only approximately fair.

**The trick.** Find two outcomes that are equally likely **for every** $p$: order is the symmetric thing, not the faces. Better schemes reuse the discarded $HH$/$TT$ rounds to waste fewer tosses.

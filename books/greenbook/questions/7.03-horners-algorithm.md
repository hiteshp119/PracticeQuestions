## Problem

Write an algorithm to evaluate $y = A_0 + A_1x + A_2x^2 + \dots + A_nx^n$.

## Solution

1. Naively, $A_kx^k$ needs $k$ multiplications: $\sum k = O(n^2)$ (or $2n$ if you keep a running power).
2. **Horner:** factor out $x$ repeatedly:
$$\begin{aligned}y = A_0 + x\Big(A_1 + x\big(&A_2 + \dots\\ &+ x(A_{n-1} + xA_n)\big)\Big).\end{aligned}$$
3. Evaluate inside out:
```
def horner(A, x):          # A[k] is the coefficient of x^k
    b = A[-1]
    for a in reversed(A[:-1]):
        b = b * x + a
    return b
```
$n$ multiplications, $n$ additions: optimal for a general polynomial.

## Intuition

**Naive approach.** Compute every power and sum.

**Why it fails.** Repeats work: $x^5$ recomputes $x^4$.

**The trick.** Re-associate so each multiplication is reused. Bonus: fewer operations also means less rounding error, and the same loop does synthetic division by $(x - c)$.

## Problem

Solve the ODE
$$y' = \frac{x-y}{x+y}.$$

## Solution

1. Let $z = x + y$, so $y = z - x$ and $z' = 1 + y'$:
$$z' = 1 + \frac{x - (z - x)}{z} = \frac{z + 2x - z}{z} = \frac{2x}{z}.$$
2. Separate and integrate:
$$\begin{aligned}z\,dz &= 2x\,dx\\ \frac{z^2}{2} &= x^2 + c\\ (x+y)^2 &= 2x^2 + C.\end{aligned}$$
3. Expand:
$$y^2 + 2xy - x^2 = C.$$
4. Check (implicit differentiation): $2yy' + 2y + 2xy' - 2x = 0 \Rightarrow y'(x+y) = x - y$. ✓

## Intuition

**Naive approach.** Try to split $\frac{x-y}{x+y}$ into $g(x)h(y)$.

**Why it fails.** A ratio of sums never factors that way.

**The trick.** Name the troublesome combination. $x+y$ appears in the denominator, so make it the new unknown; the numerator then simplifies because $x - y = 2x - z$.

**Going further.** Two other routes: (1) the right side depends only on $v = y/x$ (a *homogeneous* equation), so $y = vx$ also separates; (2) rewrite as $(x+y)\,dy - (x-y)\,dx = 0$: this is *exact*, $d\big(xy + \frac{y^2}{2} - \frac{x^2}{2}\big) = 0$, which gives the answer at once.

## Problem

Given a long array $A$ of length $m$, build the array of $n$-element moving averages
$$B_i = \frac{A_{i-n+1} + \dots + A_i}{n},\qquad i = n,\dots,m.$$

## Solution

1. Consecutive windows differ by one element in and one out:
$$S_{i} = S_{i-1} - A_{i-n} + A_i.$$
2. Algorithm:
```
def moving_average(A, n):
    s = sum(A[:n])
    B = [s / n]
    for i in range(n, len(A)):
        s += A[i] - A[i - n]
        B.append(s / n)
    return B
```
3. Cost: $O(m)$ total, versus $O(mn)$ when each window is summed from scratch.

**Numerics.** Over very long arrays the running sum can accumulate floating-point error; recompute it from scratch every so often (or use compensated summation).

## Intuition

**Naive approach.** Sum each window separately.

**Why it fails.** Each element gets added $n$ times.

**The trick.** Reuse overlapping work: the sliding-window pattern (also for rolling variance with running sums of $A$ and $A^2$, rolling max with a deque, …).

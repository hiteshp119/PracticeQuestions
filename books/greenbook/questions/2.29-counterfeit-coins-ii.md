## Problem

Five bags of 100 coins. In each bag all coins weigh the same: 9 g, 10 g or 11 g (bags may differ). With a digital scale that shows exact weight, how many weighings do you need to find each bag's coin weight?

## Solution

Write each bag's coin weight as $10 + d_i$ with $d_i \in \{-1,0,1\}$. Take $c_i$ coins from bag $i$:

$$W = 10\sum c_i + \sum_i c_i d_i.$$

1. **Two bags.** $c_1 = 1$. If $c_2 = 2$, $c_1 d_1 + c_2 d_2$ takes values in $[-3,3]$, only 7 values for $3^2 = 9$ combinations, so by pigeonhole two collide. $c_2 = 3$ gives range $[-4,4]$, 9 distinct values. ✓
2. **In general** take $c_i = 3^{i-1}$: $1, 3, 9, 27, 81$ (121 coins, base weight 1210 g). Every integer in $[-121,121]$ has exactly one representation
$$W - 1210 = \sum_{i=1}^{5} 3^{i-1} d_i,\quad d_i\in\{-1,0,1\},$$
which is **balanced ternary**. Read off the digits to get every bag. **One weighing.**

## Intuition

**Naive approach.** Use Counterfeit coins I's trick ($1,2,3,4,5$ coins).

**Why it fails.** Now **every** bag may be off, in either direction, so $3^5 = 243$ cases must map to distinct readings. Small distinct counts collide.

**The trick.** Count outcomes first ($3^5$), then pick multiplicities that make the reading a **number system** with base 3 and digits $\{-1,0,1\}$.

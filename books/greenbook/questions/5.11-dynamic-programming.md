## Problem

What is the dynamic programming (DP) algorithm for a finite-horizon sequential decision problem, and why does it work?

## Solution

1. **Model.** Stages $k = 0,\dots,N$; state $x_k$; decision $u_k$; random disturbance $w_k$:
$$\begin{aligned}x_{k+1} &= f_k(x_k, u_k, w_k),\\ \text{cost} &= g_N(x_N) + \sum_{k=0}^{N-1}g_k(x_k,u_k,w_k).\end{aligned}$$
2. **Principle of optimality.** If $\{u_0^*,\dots,u_{N-1}^*\}$ is optimal, then from any state reached at stage $k$, the tail $\{u_k^*,\dots,u_{N-1}^*\}$ is optimal for the subproblem starting there. (Otherwise, swap in a better tail and improve the whole policy.)
3. **Backward recursion.**
$$\begin{aligned}J_N(x) &= g_N(x),\\ J_k(x) &= \min_{u}\ E_{w}\Big[g_k(x,u,w) + J_{k+1}\big(f_k(x,u,w)\big)\Big].\end{aligned}$$
4. $J_0(x_0)$ is the optimal expected cost; the minimizer $u_k^*(x)$ is the policy (a decision for every state, not one fixed plan).

For maximizing profit, replace min by max. Optimal stopping is the special case where $u\in\{\text{stop},\text{continue}\}$: $J_k(x) = \max\big(\text{stop payoff},\ E[J_{k+1}]\big)$ (cards 5.12, 5.14, 5.15); American options are priced the same way.

## Intuition

**Naive approach.** Enumerate every decision sequence and every random outcome.

**Why it fails.** The number of sequences grows exponentially with the number of stages.

**The trick.** At the last stage there's nothing left to decide. Each step back only needs the values one stage ahead, so the work grows linearly in the number of stages.

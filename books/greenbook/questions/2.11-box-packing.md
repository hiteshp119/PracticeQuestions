## Problem

Can you pack 53 bricks of dimensions $1\times1\times4$ into a $6\times6\times6$ box?

## Solution

**Volume isn't enough.** $53 \times 4 = 212 \le 216$, so volume alone doesn't rule it out.

**Colouring.**

1. Cut the box into $3\times3\times3 = 27$ blocks of size $2\times2\times2$. Colour them black/white alternately like a 3D chessboard: $14$ of one colour, $13$ of the other.
2. A $1\times1\times4$ brick covers 4 consecutive cells along one axis. Along that axis the block colour flips every 2 cells, so whatever its offset the brick uses **2 cells of each colour** (2+2 across two blocks, or 1+2+1 across three).
3. The minority colour has $13 \times 8 = 104$ unit cells. Each brick needs 2 of them:
$$\#\text{bricks} \le \frac{104}{2} = 52 < 53.$$

So 53 bricks don't fit.

## Intuition

**Naive approach.** Compare volumes: $212 < 216$, so "probably yes"; or try to build it.

**Why it fails.** Volume ignores shape. Hand-building is hopeless to prove "no".

**The trick.** Find a **colouring** where every brick covers a fixed number of each colour, then count the scarce colour. Same idea as the classic mutilated chessboard: removing two same-coloured corners leaves 30 + 32 squares, but each domino needs one of each, so 31 dominoes can't fit.

## Problem

You need ordinary least squares regression, but your language has no built-in function for it. Design an algorithm. What assumptions does the linear regression model make?

## Solution

1. **Model.** $n$ observations, $p$ regressors (first column all ones for the intercept):
$$Y = X\beta + \varepsilon,\qquad Y,\varepsilon\in\mathbb R^n,\ X\in\mathbb R^{n\times p}.$$
2. **Objective.**
$$f(\beta) = (Y - X\beta)^\top(Y - X\beta).$$
3. **First-order condition.**
$$\begin{aligned}\nabla f = -2X^\top(Y - X\beta) &= 0\\ \Rightarrow\; X^\top X\,\beta &= X^\top Y.\end{aligned}$$
($f$ is convex, so this is the minimum; unique when $X$ has full column rank.)
4. **Solve via QR.** Factor $X = QR$ ($Q$: orthonormal columns, $R$: $p\times p$ upper triangular). Then $X^\top X = R^\top R$ and the normal equations become
$$R\beta = Q^\top Y.$$
5. **Back substitution.** $\beta_p = (Q^\top Y)_p / R_{pp}$, then for $i = p-1,\dots,1$:
$$\beta_i = \frac{(Q^\top Y)_i - \sum_{j>i}R_{ij}\beta_j}{R_{ii}}.$$

**Assumptions (classical OLS).** (1) linear in $\beta$; (2) $E[\varepsilon_i \mid X] = 0$; (3) constant variance and uncorrelated errors, $\operatorname{Var}(\varepsilon) = \sigma^2 I$; (4) no perfect multicollinearity (full column rank); for exact inference, (5) normal errors. Under (1)–(4), OLS is BLUE (Gauss–Markov).

## Intuition

**Naive approach.** $\beta = (X^\top X)^{-1}X^\top Y$ with a matrix inverse.

**Why it fails.** Inverting is slower and loses accuracy: forming $X^\top X$ squares the condition number, so nearly collinear regressors blow up the error.

**The trick.** Least squares is a **projection**: the best fit $X\beta$ is the point in the column space of $X$ closest to $Y$, so the residual is orthogonal to every column ($X^\top\text{residual} = 0$). QR gives an orthonormal basis of that column space directly, leaving only an easy triangular system.

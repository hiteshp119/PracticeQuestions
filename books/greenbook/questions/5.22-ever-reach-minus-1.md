## Problem

$X_t$ satisfies $dX = dt + dW_t$ with $X_0 = 0$. What is the probability that $X$ ever reaches $-1$?

## Solution

1. With $m = 1$, $Z_t = e^{-2X_t}$ is a martingale (card 5.21).
2. Add an upper barrier $a$; let $p_a = P(\text{hit } {-1} \text{ before } a)$:
$$p_a e^{2} + (1 - p_a)e^{-2a} = e^{0} = 1 \;\Rightarrow\; p_a = \frac{1 - e^{-2a}}{e^2 - e^{-2a}}.$$
3. Let $a\to\infty$ (the drift carries $X$ to $+\infty$, so "never hit $-1$" = "hit every $a$ first"):
$$P = \lim_{a\to\infty}p_a = e^{-2}\approx 0.135.$$
In general, with drift $m>0$, $P(\text{ever reach } -b) = e^{-2mb}$.

## Intuition

**Naive approach.** "The drift pushes X up forever, so the probability is 0," or "Brownian motion hits every level, so it's 1."

**Why it fails.** Early on, noise ($\sqrt t$) dominates drift ($t$), so a dip to $-1$ is possible; later the drift wins and the chance disappears.

**The trick.** Use a second, distant barrier to make optional stopping legal, then send it to infinity. The exponential martingale turns the drift into a simple exponential weight.

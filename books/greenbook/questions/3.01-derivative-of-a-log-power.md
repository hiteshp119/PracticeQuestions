## Problem

For $x > 1$, find $\dfrac{dy}{dx}$ when
$$y = (\ln x)^{\ln x}.$$

## Solution

1. Take logs:
$$\ln y = \ln x \cdot \ln(\ln x).$$
2. Chain rule on the inner piece ($v = \ln x$):
$$\frac{d}{dx}\ln(\ln x) = \frac{1}{\ln x}\cdot\frac1x.$$
3. Product rule:
$$\begin{aligned}\frac{y'}{y} &= \frac{1}{x}\ln(\ln x) + \ln x\cdot\frac{1}{x\ln x}\\ &= \frac{\ln(\ln x) + 1}{x}.\end{aligned}$$
4. Multiply by $y$:
$$y' = \frac{(\ln x)^{\ln x}}{x}\big(\ln(\ln x)+1\big).$$

**Book note.** The book writes the function as $\ln x^{\ln x}$; its solution treats it as $(\ln x)^{\ln x}$, as here. Read as $\ln\!\big(x^{\ln x}\big) = (\ln x)^2$ it would simply give $2\ln x / x$.

## Intuition

**Naive approach.** Power rule: $y' = \ln x\,(\ln x)^{\ln x - 1}\cdot\frac1x$.

**Why it fails.** The power rule needs a constant exponent; here the exponent moves too, so a second term is missing.

**The trick.** Logs turn powers into products: $\ln y = g\ln f$. Then
$$y' = f^{g}\Big(g'\ln f + g\,\frac{f'}{f}\Big),$$
which is "power rule + exponential rule" added together. Here $f = g = \ln x$.

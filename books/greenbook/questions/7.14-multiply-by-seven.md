## Problem

Give a fast way to multiply an integer by 7 without using the multiplication operator.

## Solution

1. `x << k` shifts the bits left by $k$, i.e. multiplies by $2^k$.
2. $7 = 2^3 - 1$:
$$7x = 8x - x = (x \ll 3) - x.$$
3. Example: $x = 5 = 101_2$: $x\ll3 = 101000_2 = 40$, $40 - 5 = 35$. ✓
4. Caveat: overflow if $8x$ exceeds the integer range (and left-shifting negative numbers is undefined in older C).

Generally, any constant multiply decomposes into shifts and adds from its binary form, e.g. $10x = (x\ll3) + (x\ll1)$.

## Intuition

**Naive approach.** Add $x$ to itself 7 times.

**Why it fails.** Seven additions, versus one shift and one subtraction.

**The trick.** Think in binary: multiplication by powers of 2 is free (a shift). Compilers do this automatically for constant multipliers.

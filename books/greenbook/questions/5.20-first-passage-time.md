## Problem

Let $W_t$ be a standard Brownian motion and $\tau_x = \min\{t: W_t = x\}$ for $x>0$. Find the density of $\tau_x$ and its expected value.

## Solution

1. **Reflection.** For a path with $\tau_x\le t$, flip it after $\tau_x$ (reflect across level $x$). This is a measure-preserving bijection between paths ending above $x$ and paths ending below $x$:
$$P(\tau_x\le t,\ W_t\ge x) = P(\tau_x\le t,\ W_t\le x).$$
2. Paths with $W_t\ge x$ have certainly hit $x$, so
$$P(\tau_x\le t) = 2P(W_t\ge x) = 2\Big(1 - N\big(\tfrac{x}{\sqrt t}\big)\Big).$$
3. Differentiate ($\frac{d}{dt}\frac{x}{\sqrt t} = -\frac{x}{2t^{3/2}}$):
$$f_{\tau_x}(t) = 2\,\varphi\Big(\frac{x}{\sqrt t}\Big)\frac{x}{2t^{3/2}} = \frac{x}{\sqrt{2\pi t^3}}e^{-x^2/2t}.$$
4. $t\to\infty$: $P(\tau_x<\infty) = 2(1 - N(0)) = 1$. But the tail $f\sim t^{-3/2}$ makes $E[\tau_x] = \int t f\,dt$ diverge. Also: the exit time from $(-b, x)$ has mean $bx$ (card 5.19), which $\to\infty$ as $b\to\infty$.

## Intuition

**Naive approach.** "Brownian motion surely hits $x$, so it does so in finite expected time."

**Why it fails.** It hits $x$ with probability 1, but some paths wander far below first and take enormously long.

**The trick.** Reflection again (compare card 5.09): count the hard event via a bijection with an easy one. Bonus: the running maximum $M_t$ satisfies $P(M_t\ge x) = P(\tau_x\le t) = P(|W_t|\ge x)$, so $M_t\overset d= |W_t|$.

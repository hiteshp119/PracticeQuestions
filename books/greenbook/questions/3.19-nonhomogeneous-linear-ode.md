## Problem

Find the general solutions of
$$\text{(a)}\ \ y'' + y' + y = 1,\quad \text{(b)}\ \ y'' + y' + y = x.$$

## Solution

1. **Homogeneous part** (card 3.18): $r^2+r+1=0$, $r = -\frac12\pm i\frac{\sqrt3}2$:
$$y_h = e^{-x/2}\Big(c_1\cos\tfrac{\sqrt3}{2}x + c_2\sin\tfrac{\sqrt3}{2}x\Big).$$
2. **(a)** Try a constant $y_p = k$: $0 + 0 + k = 1 \Rightarrow k = 1$.
$$y = y_h + 1.$$
3. **(b)** Try $y_p = mx + n$: $y_p'' + y_p' + y_p = 0 + m + mx + n = x$. Match coefficients:
$$x:\ m = 1,\qquad 1:\ m + n = 0 \Rightarrow n = -1.$$
$$y = y_h + x - 1.$$

## Intuition

**Naive approach.** Hunt for one clever formula that solves the whole equation.

**Why it fails.** There's no closed form for general right sides, and a single solution misses the two free constants.

**The trick.** Split the job: if $y_1, y_2$ both solve $Ly = d$, then $L(y_1 - y_2) = 0$. So **all** solutions = one particular + the homogeneous family. Find the particular one by guessing the *shape* of the right side (polynomial → polynomial, $e^{kx}$ → $e^{kx}$, …) with unknown coefficients.

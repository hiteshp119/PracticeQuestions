## Problem

You have a generator of independent standard normals. How do you generate two $N(0,1)$ variables with correlation $\rho$? How does this extend to a multivariate normal $N(\mu,\Sigma)$?

## Solution

1. Draw independent $z_1, z_2 \sim N(0,1)$ and set
$$x_1 = z_1,\qquad x_2 = \rho z_1 + \sqrt{1-\rho^2}\,z_2.$$
2. Check:
$$\begin{aligned}\operatorname{Var}(x_2) &= \rho^2 + (1-\rho^2) = 1,\\ \operatorname{Cov}(x_1,x_2) &= \operatorname{Cov}(z_1,\rho z_1) = \rho.\end{aligned}$$
Linear combinations of jointly normal variables are normal, so both are $N(0,1)$ with correlation $\rho$.
3. In matrix form this is $X = LZ$ with
$$L = \begin{pmatrix}1&0\\ \rho&\sqrt{1-\rho^2}\end{pmatrix},\qquad LL^\top = \begin{pmatrix}1&\rho\\\rho&1\end{pmatrix}.$$
4. **General case.** For $\Sigma$ positive definite, Cholesky gives $\Sigma = LL^\top$ ($L$ lower triangular, positive diagonal). Then
$$X = \mu + LZ \;\Rightarrow\; \operatorname{Cov}(X) = L\,I\,L^\top = \Sigma.$$
Any $A$ with $AA^\top = \Sigma$ works, e.g. from the eigendecomposition $\Sigma = UDU^\top$: $A = UD^{1/2}$ (useful when $\Sigma$ is only semidefinite).

## Intuition

**Naive approach.** Set $x_2 = \rho z_1 + (1-\rho) z_2$, mixing "weights" that add to 1.

**Why it fails.** Variances add as **squares**: $\operatorname{Var} = \rho^2 + (1-\rho)^2 < 1$ for $0<\rho<1$.

**The trick.** Geometry again: $x_2$ is a unit vector at angle $\arccos\rho$ from $z_1$, so its coordinates are $(\cos\theta, \sin\theta) = (\rho, \sqrt{1-\rho^2})$. Cholesky is the $n$-dimensional version of "write each new vector in terms of the previous orthonormal directions".
